# 同樂70週年大富翁：校園嘉年華

同樂國小 70 週年校慶紀念遊戲。在員山鄉與結頭份歌仔戲原鄉的校園地圖上，認養土地、升級戲台、挑戰問答。

- 適合對象：國小 2–6 年級
- 人數：2–6 人（可加入電腦玩家）
- 玩法：同一台裝置輪流進行，適合投影或小組使用
- 版本：v4.1（2026-10-29，手機／平板版面調整）

## 如何開始

用瀏覽器開啟遊戲網址即可，不需要安裝、不需要登入。

> 遊戲網址：https://hsiao103.github.io/tongle-monopoly/
>
> （若你的儲存庫名稱不是 `tongle-monopoly`，請把網址與 `index.html` 內 `og:image` 的網址一併修改。）

也可以把 `index.html` 下載後直接用瀏覽器開啟，離線也能玩。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `index.html` | 遊戲本體（單一檔案，含畫面、規則與內建題庫） |
| `preview.jpg` | 分享連結時顯示的預覽圖 |
| `docs/question-bank-template.csv` | 題庫試算表範本（現有 37 題，標準欄位格式） |
| `docs/ai-prompt-template.txt` | 老師／AI／學生出題與審核範本 |

## 更新題庫

目前題庫寫在 `index.html` 內，搜尋 `id="qbank"` 即可找到。每題格式如下，第一個選項是正確答案，遊戲會自動打亂順序：

```json
{"c":"類別","lv":1,"q":"題目","o":["正解","錯1","錯2","錯3"],"e":"解說"}
```

`lv` 為 1 代表 2–3 年級、2 代表 4–6 年級。

CSV 匯入功能規劃中，標準欄位格式請見 `docs/`。

## 資料來源

題目內容參考下列公開資料，皆已改寫為題目，並於題庫範本的「出處」欄記錄：

- 宜蘭縣員山鄉鄉土教材

部分題目標示「待查證」，使用前請由老師確認。
